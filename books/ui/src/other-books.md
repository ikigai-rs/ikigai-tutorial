# The other books

This book builds on [The ikigai Book](../index.html), which teaches resources, spaces,
capabilities and golden threads from the first endpoint up, and is written beside
[The gonk Book](../gonk/index.html), the work ledger and review host built from the same pieces, and
[The ikigai Architecture](../architecture/index.html), which shows how those pieces fit.
[Running ikigai](../operations/index.html) is the operator's book: the `ikigai` binary, and what it
takes to serve and run kernels for real.

[The library](../library/index.html) lists all five, with who each is for, what to read first and
where to start.

The books are built, tested and published together, from one repository:
<https://github.com/ikigai-rs/ikigai-tutorial>.
