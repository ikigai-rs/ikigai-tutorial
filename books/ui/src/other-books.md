# The other books

This book builds on [The ikigai Book](../index.html), which teaches resources, spaces,
capabilities and golden threads from the first endpoint up, and is written beside
[The gonk Book](../gonk/index.html), the work ledger and review host built from the same pieces.

[The library](../library/index.html) lists all three, with who each is for, what to read first and
where to start.

The three books are built, tested and published together, from one repository:
<https://github.com/ikigai-rs/ikigai-tutorial>.
