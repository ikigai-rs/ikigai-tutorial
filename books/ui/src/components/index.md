# Components across targets

*This part is not written yet.*

It will cover the ikigai components: custom elements for the things worth embedding in a page
you did not write (a ledger, an item, a layer, a resource card, a refusal, the theme chooser).
Each component will be rendered on the server and work as a link with no script. It will use
the [token set](../model/themes.md) for its theme, describe the resource it shows, and use
the page's authority or a scoped, read-only token.

The chapter will show a component built once and used from more than one delivery target.
