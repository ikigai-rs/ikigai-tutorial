# The other books

Four more books build on this one, and each runs in the page as this one does.

- [The gonk Book](gonk/index.html): gonk, the work ledger and review host, composed from the pieces
  this book teaches. Start there for a ledger of your own, in the page and on your machine.
- [Building ikigai UIs](ui/index.html): a view is a resource too. It builds a kernel inspector from
  the cache, the golden threads and the arrangement this book prints as text.
- [The ikigai Architecture](architecture/index.html): how the pieces fit, carrying one ledger item
  through capabilities, the door, the overlay chain, caching and the audit axis. Read it after this
  book's chapters on dynamic spaces.
- [Running ikigai](operations/index.html): the operator's book. The `ikigai` binary, its flags and
  subcommands, and what it takes to serve, secure and run kernels for real, with every command run
  against a pinned release whenever the books are built.

[The library](library/index.html) lists all five, with who each is for, what to read first and where
to start.

The books are built, tested and published together, from one repository:
<https://github.com/ikigai-rs/ikigai-tutorial>.
